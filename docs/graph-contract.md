# 图谱接入契约

内置数据为合成样例，目的是在本机复现课程展示场景。实际图谱部署前应冻结所用数据库版本、Schema 快照、图谱分支和审阅人。服务将实际 Schema 与配置映射计算为一个哈希，写入每题记录。

## 样例模型

| 角色 | 节点标签 | 名称字段 |
| --- | --- | --- |
| service | 微服务 | 服务名称 |
| class | 类 | 类名 |
| method | 方法 | 方法名 |
| api | API 端点 | 接口路径 |
| exchange | 消息通信交换机 | 交换机名称 |
| queue | 消息队列 | 队列名称 |
| config | 配置文件节点 | 文件名 |
| test | 测试用例 | 用例名 |

实体以全局 ID 作为身份。其余公共字段为仓库、分支和文件路径。对同名实体显示直属类、所属服务、仓库、分支与路径。用户显式限定仓库或分支时，该过滤应用到路径中所有节点。

| 关系语义 | 样例方向 |
| --- | --- |
| 归属 | 子实体 → 父实体。样例包含方法或 API → 类 → 服务 |
| 调用 | 调用方 → 被调用方。样例包含 API → 方法和方法 → 方法 |
| 导入 | 类 → 被导入类 |
| 接口实现 | 实现类 → 接口类 |
| 继承 | 子类 → 父类 |
| 消息流 | 发布方法 → 交换机 → 队列 → 消费方法，阶段存于关系属性 |

跨服务 RPC 由方法调用路径与方法所属服务判断，在默认跳数内包含传递依赖。MQ 链路分为发布、路由、消费。两种机制按目标服务 ID 合并，保留各自证据。同一条路径的节点保持唯一。路径列表显示遍历顺序，拓扑边箭头显示数据库关系方向。

## Neo4j 权限与验证

在管理员批准的环境中开设独立账号，授予目标图谱的读取与必要元数据访问权限。可参考 Neo4j 的自定义角色示例，以具体 database 和 graph 名限定权限。后端仅用固定元数据过程 `db.schema.nodeTypeProperties` 和 `db.schema.relTypeProperties` 获取快照。校验器使用当前快照约束编译，再对生成查询执行 `EXPLAIN`。切换映射后重启应用生效，元数据快照每 5 分钟刷新一次。Neo4j 官方资料见 [细粒度访问控制](https://neo4j.com/docs/operations-manual/current/tutorial/access-control/)。
